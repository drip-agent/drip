## Strategy

### Image Recommendations (ranked by engagement)
1. **Terminal teaser** (`/api/social/teaser`) — best for Tweet 1. Shows real output, real data, creates "wait, that actually works?" reaction
2. **Landing page terminal section** — best for Thread. Shows the full product in context with the dark UI
3. **Agent chat page** (`/agent`) — best for Tweet 3. Shows the web interface, suggests a full product beyond just CLI
4. **Interactive menu screenshot** — best for Tweet 4. Dev-focused, shows the DX

### Posting Order
- **Tweet 1** first (standalone teaser, let it breathe 24h)
- **Tweet 3** next day (shows depth — not just CLI, full agent)
- **Tweet 2 + 4** as thread replies to build narrative

### Hashtags (use sparingly, 1-2 max)
- `$DRIP` (token awareness)
- Skip generic tags like #AI #crypto — they dilute signal

### Tone
- Lowercase, calm, understated
- No emojis except 💧
- Let the screenshot do the talking
- "drip.surf" as the closer, not a CTA — curiosity > urgency
